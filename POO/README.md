# ☕ Programação Orientada a Objetos (POO) com Python

Este diretório é dedicado ao armazenamento dos meus códigos e anotações sobre **POO utilizando a linguagem Python**. Atualmente, estou acompanhando as aulas e resolvendo as atividades propostas pelo [Curso em Vídeo](https://cursoemvideo.com), do professor Gustavo Guanabara.

## 📌 Estrutura dos Arquivos
* **Desafios 001 ao 015:** São desafios **teóricos e conceituais** propostos pelo curso para consolidar a base lógica sobre o paradigma orientado a objetos. Decidi separar cada um deles em seu próprio arquivo `.py` contendo as perguntas, alternativas e explicações em formato de comentário Python.
* **Desafios 016 em diante:** Códigos práticos em Python contendo a criação de classes, métodos, encapsulamento, herança e polimorfismo.

O objetivo desta pasta é registrar toda a minha evolução teórica e prática durante o aprendizado de POO no ecossistema Python.
